# Voxonta для Nextcloud

Самостоятельный установочный комплект: `voxonta-app.tar.gz` для существующего
Nextcloud и настроенный захват Nextcloud Talk. Matrix, Synapse, Element, LiveKit
и пакет Voxonta для Matrix для работы не требуются.

1. Установите включённый архив `voxonta-app.tar.gz` как приложение `voxonta`
   в существующий Nextcloud. При обновлении сохраните прежнюю версию и данные;
   выполните штатное обновление приложения через интерфейс или `occ upgrade`.
2. В настройках Voxonta задайте адрес/ключ шлюза и сервисный ключ захвата.
   Настройте бот-аккаунт и доступ Talk согласно README приложения.
3. Скопируйте `.env.example` в `.env`. Укажите NEXTCLOUD_URL и те же ключи
   сервисного API/шлюза. Пароли Nextcloud в этот файл переносить не требуется:
   захват получает их через служебный API приложения.
4. Запустите `docker compose up -d --build` из каталога комплекта.
5. Проведите тест Talk: старт, пауза/продолжение, завершение, расшифровка в архиве.

Контейнер capture — внутренняя часть поставки. Не нужно отдельно искать или
устанавливать пакет с другим названием. Образ не устанавливает LiveKit SDK.
Проверка: `docker compose ps`, `docker compose logs --tail=100 capture`.
Остановка: `docker compose down`. Данные архива остаются в существующем Nextcloud.
Не обновляйте работающий захват во время звонков. Модель распознавания работает
в Voxonta; ни движок SaaS, ни другую интеграцию на сервер ставить не нужно.
